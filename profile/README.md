grug is a programming language with one job: make your mods immortal.

A mod written in grug today should keep running 100 years from now, however much the game around it changes. A Minecraft mod written in grug aims to run in every version of the game, from Alpha 1.1.2_01 (2010) to the latest, without any changes to its source code. And because a mod can only call what the game declares in its `mod_api.json`, moderators do not need to review mods for security.

**Start here: [grug-lang/grug](https://github.com/grug-lang/grug)**, the language, its README, and the list of implementations and games that use it.
